# cowrite

本地运行的写作台：Markdown 编辑、自动保存、AI 润色、语音输入、一键发布到多个平台。

文章以普通 `.md` 文件存在你自己的目录里，可以用 git 管理，也可以随时用别的编辑器打开——
这个工具不持有你的内容。

```bash
make build
./bin/cowrite
# 浏览器打开 http://127.0.0.1:8080
```

## 它能做什么

**写**
- 分栏实时预览，服务端渲染，所见即所得
- 自动保存（800ms 防抖 + 原子写，崩溃不会写出半个文件）
- 版本历史，可预览再恢复；恢复本身也会先存快照
- 在 vim 里改同一个文件，编辑器里会自动同步；有未保存内容时只提醒，不覆盖
- 全文搜索（中文可用）

**AI**
- 润色 / 续写 / 起标题 / 摘要，流式输出，可中途停止
- 选中文字后改写，结果确认后才写入
- 任何 OpenAI 兼容端点都能接：DeepSeek、通义千问、Kimi、OpenAI，或本地 Ollama
- 密钥存系统钥匙串，不进工作区、不进索引、不回传浏览器

**语音**
- 按住 F2 说话，松开转写
- 转写之后有一道 AI 清洗：去口水词、删重复、识别说到一半的改口、口述清单转成列表
- 原始转写始终保留，可一键切回
- 选中文字后说指令（「改短一点」），直接改写选区

**发布**
- 微信公众号：官方 API，进草稿箱，封面和正文图片自动上传
- 知乎 / 掘金 / CSDN / 思否 / 公众号：通过配套浏览器扩展填进平台编辑器
- 一键复制为公众号格式（内联样式，粘进去排版不散）
- 导出 Markdown 或独立 HTML

**排版**
- 代码高亮、表格、公式、Mermaid 图表，全部纯 Go 渲染，不需要 Node
- 多套主题，可自己加 CSS

## 配置

第一次打开点 ⚙ 配置 AI。本机装了 Ollama 或 LM Studio 的话会自动探测到，不用填 key。

常用参数：

```bash
./bin/cowrite --port 8080 --workspace ~/cowrite
```

## 浏览器扩展（可选）

知乎、掘金这些平台没有开放的写接口，只能借你已经登录的浏览器。

1. Chrome 打开 `chrome://extensions`，开启「开发者模式」
2. 「加载已解压的扩展程序」，选本项目的 `extension/` 目录
3. 点扩展图标，填端口和配对码（在 cowrite 的发布对话框里）

内容只填进平台编辑器，**不会自动点发布**——最后一步你自己确认。

## 安全

- 默认只绑 `127.0.0.1`。这个服务没有登录机制，不要绑到 `0.0.0.0`
- 扩展用的 WebSocket 会校验来源和配对码，防止你访问的任意网页连上来读文章、以你的身份发内容
- API 密钥走系统钥匙串，没有钥匙串时降级到 0600 权限的文件
- 语音音频转写完即丢，不落盘

## 已知限制

- **微信官方 API 需要已认证的订阅号/服务号**，还要把本机公网 IP 加进后台白名单（家用宽带 IP 会变）。没有认证号可以走扩展通道
- **平台选择器会失效**。各家编辑器改版后适配器就要跟着改，注入失败会明确报「编辑器结构可能变了」
- **公式和 Mermaid 用的是 pre-1.0 的 Go 重实现**，排版结果和 KaTeX / mermaid.js 不完全一致；渲染失败会保留源码而不是丢内容
- 搜索用 LIKE 扫表。FTS5 没有中文分词器，unicode61 完全匹配不了中文，trigram 又漏掉两字词——单人工作区这个量级直接扫更准
- 编辑器是 textarea，没有语法高亮和行号

## 开发

```bash
make test      # 全部测试
make vet
make release   # 交叉编译 macOS / Linux / Windows
```

Go ≥ 1.26.4（公式库要求）。前端是原生 TypeScript，没有构建步骤。
