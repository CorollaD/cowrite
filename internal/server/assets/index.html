发布到微信公众号

需要已认证的订阅号或服务号。公众号后台要把本机公网 IP 加进 「设置与开发 → 基本配置 → IP 白名单」，家用宽带 IP 变动后需要重新添加。
文章会进入草稿箱，不会直接群发。最后一步请到公众号后台确认后再发。
公众号要求必须有封面图：在文章 front matter 里写 cover: 文件名.png，图片放在文章同一个目录下。
